# 📚 Readme AI Agent — Multi-Novel Platform Brain

Dokumentasi terstruktur 12-file standar arsitektur AI agent untuk pengembangan dan pemeliharaan platform web novel *Tiket Pulang Paling Sunyi* dan novel-novel mendatang.

## 🗂️ Indeks File Otak Proyek
1. `AGENT.md`: Checkpoint status agen langsung (< 150 token).
2. `PRD.md`: Product Requirements Document (katalog multi-novel, auto-slug routing, spesifikasi pembaca).
3. `TECHSTACK.md`: Kontrak teknologi (Next.js 14 Static Export, Web Audio API, Service Worker v5, Vercel Edge).
4. `SECURITY.md`: Protokol keamanan 7-layer (CSP header, sanitasi teks, zero-serverless attack surface).
5. `SKILLS.md`: Registri skill dan kapabilitas aktif (`opus-distills`, `web-planning`, `web-builder`, `web-debugging`).
6. `STYLE-GUIDE.md`: Pedoman visual sastra editorial (Krem/Kertas, Sepia, Malam, tipografi Merriweather/Charter).
7. `TASK.md`: Daftar tugas berbutir eksekusi multi-novel platform.
8. `SEO-GEO.md`: Pemetaan metadata OpenGraph, Schema.org Book/Series, `sitemap.ts`, dan `robots.ts`.
9. `BUG-AND-FIX.md`: Buku besar riwayat masalah dan solusi (cache audio v1-v5, nama tokoh, spectral cutoff).
10. `GIT-RESTORE-POINTS.md`: Catatan commit Git dan titik pemulihan.
11. `DESIGN-CRITIQUE.md`: Rubrik audit visual 7-viewport (Mobile 390px, Tablet, Desktop).
12. `README.md`: Ringkasan navigasi folder ini.
