# 🎨 Style Guide & Visual DNA — Multi-Novel Platform

## 1. Filosofi Estetika: Sastra Klasik Hangat (Literary Warmth)
Menghadirkan kenyamanan buku fisik cetak berkualitas tinggi di atas layar kaca ponsel dan monitor komputer. Anti-AI slop, anti-gradien ungu generik (`#6366f1` dilarang).

## 3. Tipografi
- **UI & Navigasi**: Sans-serif modern berkelas (`Plus Jakarta Sans` / `Inter` / system-ui).
- **Isi Bacaan Novel**: Book Serif dengan keterbacaan tinggi (`Merriweather` / `Lora` / `Georgia` / `Charter`).
- **Jarak Baris (Line-Height)**: `1.85` - `1.95` (mencegah baris teks saling tumpuk saat membaca lama).
- **Panjang Baris Optimal**: Maksimal `68ch` - `75ch` agar mata tidak lelah menyapu dari kiri ke kanan.

## 4. Komposisi Kartu Novel Katalog
- Rasio sampul buku: 3:4 atau 2:3 dengan sudut melengkung halus (`rounded-2xl`).
- Indikator status: Badge kecil elegan bertuliskan *Tamat* (Hijau Zaitun Sastra) atau *Segera Terbit* (Emas Muted).
- Tagar genre: Huruf kapital mini (`text-xs uppercase tracking-wider`).
